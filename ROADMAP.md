## Verdict

AIrail is not a meter; it is peripheral vision for AI capacity, and everything mindblowing about it lives on the one surface no rival has: a hairline on the edge of the screen that breathes for free (Core Animation, 0% CPU), fills along its length with your nearest limit, glints while Claude Code is actually generating, sweeps amber before you notice, and, on the notch, unfurls on its own for three seconds when a window resets or you cross 90%, then tucks away. The card underneath earns its glass by being honest-by-construction: stale numbers expire at their own reset, the wall leads with the time until it lifts, pace is arithmetic on server truth rather than slope-fitting, 'used elsewhere' explains a ring that moved while this Mac was idle, and every estimate says 'est.'. Then the Mac itself seems to know how much AI you have left: Siri and Shortcuts answer 'Claude is at 62%, resets in 2h 40m', a Focus filter quiets the rail, a Claude Code status line reads the same numbers, a hotkey peeks. All of it ships on a trust story CodexBar cannot copy because it is a menu-bar meter farm: one allowlisted network path, no cache, no cookies, hardened and attested builds, a Privacy pane that lists every host ever contacted, and a consent card before the first Keychain read. The rail, the restraint, and the read-only brand are the pitch, and they stay free.

**Two corrections to the 2026-09-05 morning assessment.** `NSWindow.sharingType = .none` is documented by Apple as "a legacy constant that macOS no longer uses… Don't use this value to hide or omit content from being captured" (verified against developer.apple.com on 2026-09-05), so hide-on-screen-share is cut. SwiftUI `.redacted(reason: .privacy)` only affects Text and Image; rings, share bars and chart bars are Shapes and keep drawing real percentages, so the redaction-based demo face is cut. A names-only redaction Bool (email, plan, projects; rings stay real) is the honest replacement if wanted (decision 2).

## What the research changed

- **CodexBar moved.** v0.56.x, ~21k stars, 69 providers, near-daily releases: pace forecasting ("lasts until reset"), WidgetKit widgets, 365-day local history, hourly heatmap, per-project/conversation cost, multi-account, hide-personal-information mode, iCloud sync, CLI + `serve` dashboard + JSON, hooks, provider plugins, adaptive refresh, 21 languages. Still menu-bar only. The README comparison table understates the gap; replace it with a "why the edge" story.
- **The notch is not a moat.** CodexIsland, Claude Notch Tracker, NOTCHYLIMIT, Notchy, Vibe Island, Ping Island all put usage in the notch or a drawn island. Nobody does a screen-edge rail with per-display placement and an ambient hairline. Lead with the rail.
- **Platforms changed under the data model (Apr–Aug 2026).** Copilot monthly plans bill AI credits in dollars (from June 1) plus session and weekly token×multiplier lanes (from April 20); AIrail reads the legacy `quota_snapshots` shape. Cursor split included usage into two pools (Cursor Models vs Other Models) plus on-demand; AIrail shows one `totalPercentUsed`. Codex Plus regained a 5-hour window on Aug 26 while Pro is temporarily exempt: a missing window must not read as 0%. Google shut the consumer Gemini tier (18 Jun 2026) and points to Antigravity. OpenRouter added an Activity dashboard and Analytics API; AIrail reads only credits.
- **Defects found in v0.2.0 that the README contradicts.** (1) The default `URLSession` disk cache holds bearer tokens and cookies, so "keeps no tokens on disk" is false. (2) `RailHairline`'s 20 Hz `TimelineView` measured ≈4.8% CPU idle with a full layout pass per tick. (3) The shipped DMG carries `get-task-allow`, so any same-user process can attach a debugger. (4) `ModelPricing` makes an undisclosed weekly call to openrouter.ai (principle 3) and the demo card prints dollars from it. (5) `UpdateChecker` can run a modal `NSAlert` over the user's work from the background timer. (6) The first notification after launch is dropped and 75/90% re-fire on relaunch. (7) A 403 HTML body reads as "sign-in expired".
- **Table stakes moved.** Threshold + pace + reset alerts, per-model buckets, an extra-usage/credits bar, history deeper than 7 days, a scripting surface (JSON/CLI/statusline), widgets, multi-account. AIrail has the first two.
- **The biggest gap is distribution.** Private, un-notarized, not on Homebrew, while every serious rival is one `brew install --cask` away. macOS 15 removed the Control-click "Open" bypass the README describes; users now need System Settings › Privacy & Security › Open Anyway. The Developer ID ($99/yr) is the prerequisite for the free path as well as any paid one.

## The eight moments (all tier 1)

1. **The hairline becomes a gauge** (`ambient-headroom`): fills along its length with the nearest limit; idle island caption reads "Claude 91% · Codex 12% · resets 14:30".
2. **Agent now playing** (`agent-now-playing`): a travelling glint while Claude Code/Codex generates; caption "Opus · working · 142K context" from an FSEvents tail of the transcripts.
3. **Island announcements** (`island-announcements`): at a reset or 90% crossing the notch unfurls for 3 s with "Claude · session reset" / "Claude 90% · Codex has headroom", then tucks away.
4. **At the wall, lead with the time** (`critic-6-at-the-wall-lead-with-the-time`): at 100% every caption and the ring centre count down to the reset.
5. **Used elsewhere** (`critic-7-used-elsewhere`): the ring climbed while nothing ran on this Mac → the card says so.
6. **Siri and Shortcuts** (`shortcuts-siri-app-intents`): two App Intents answering from the cached snapshot, never fetching, never a Keychain prompt.
7. **Desk mode** (`desk-mode-both`): island in the MacBook notch and the rail on the far monitor at once.
8. **Privacy & Security pane** (`privacy-pane`): what AIrail reads, every host contacted and when, what it keeps, what this build is, Remove All Data.

## Cut, with the skeptic's blocker

- **Cache and reasoning mix ('≈ $41 saved by prompt caching')** — Prices a counterfactual no Claude Code user can pay (computes to ≈ $3,706 'saved' against a $626 value line on this Mac) and the restart count swings 8x with the rule; four numbers for facts the user cannot change.
- **Cost per commit, per project** — Counting commits under Documents/Desktop needs a Files & Folders TCC prompt fired from a refresh timer, widens the trust footprint to every repo's commit log, and divides an estimate by a proxy.
- **Hide from screen sharing switch (NSWindow.sharingType = .none), previously judged tier 1** — Apple documents .none as legacy and says not to use it to hide content; ScreenCaptureKit ignores it on macOS 15.4+, so a labelled switch would silently fail in Zoom, Meet and QuickTime on the macOS most users run, a false sense of privacy.
- **Demo face / privacy redaction mode, previously judged tier 1** — Redaction affects Text and Image only; the rings, share bars and chart bars are Shapes that keep drawing the real percentages, so a redacted card looks broken, not private, and the collapsed surfaces already expose only names and percents.
- **Recap card now (before go-public)** — An estimate on a poster with four brand marks is trademark and trust exposure with no verified identity behind the release; ImageRenderer cannot render the HUD's glass or AppKit-backed controls anyway. Returns in tier 2 behind notarized release plus the ledger.
- **Soft caps, month-end bill projection, idle-subscription flag, previously judged tier 2** — No cap is reachable through any read-only endpoint AIrail uses, so an AIrail-set cap would disagree with the platform's; both need a per-account preferences container and history that do not exist. Only the spend-footer relabel ships.
- **Personal-baseline pace trigger (3x your typical hour)** — On this Mac's real week it fires on 8 of 42 active hours; agentic bursts are the normal mode, so 'your typical hour' is not a stable baseline. Replaced by a projection-based pace alert.
- **Windsurf provider** — Its state.vscdb cache only refreshes when Windsurf launches, so a daily quota ring would be hours wrong even labelled 'cached'; the only live path is Chromium localStorage plus Full Disk Access, which is cookie scraping.
- **Zed provider** — Every paid Zed plan has unlimited edit predictions and the monthly credit is not in the response, so a Keychain prompt would buy a mark with no ring for paying users. Deferred, not blocked.
- **Codex session-log fallback for a drifted endpoint** — A second unofficial parser defending the first (its shape already moved between June and August), producing a 'stale but 3 minutes old' ring that muddies the status vocabulary; 18 days stale on this Mac today.
- **30 Days chart segment** — Claude's default 30-day transcript retention makes the left edge of a 30-day chart an artefact; Copilot has no history source, Cursor's backfill can exceed its page cap, and the Battery pane stops at 10 days.
- **Compiled `airail` helper before notarization** — An un-notarized nested binary keeps its quarantine xattr and can raise 'developer cannot be verified' from a status line Claude Code execs every 300 ms. Waits for the Developer ID and a Homebrew binary stanza.
- **Data-protection Keychain for AIrail's own keys** — Fails with errSecMissingEntitlement without a Team ID, delivers nothing a stable signing identity does not already deliver, and its migration read triggers the very prompt it claims to avoid.
- **Trackpad swipe, push transition and pinned account in the HUD** — No Mac precedent for swipe inside a HUD (fights the chart's hover callout), the transition briefly holds two heights, and a pin adds a Defaults key plus a concept that digits and List.onMove already cover.
- **Team pulse, haptics, Ollama ring, $2 Guard tier (already assessed)** — Contradict no-cloud, only fire during trackpad interaction, have no limit to ring, and gate free features behind a forkable paywall respectively; unchanged from the earlier assessment.
